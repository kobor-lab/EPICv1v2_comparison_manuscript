# EPICv1v2_comparison_manuscript
Including exampler script for 
1. Sample-to-sample correlation and hierarchical clustering using the Euclidean distance with complete linkage to compute the distance for the sample-to-sample correlations
2. Calculate probe-level Spearman correlations, RMSE, and pooled SD
3. Technical replicate ICC calculation (array-level)
4. Epigenetic age acceleration (EAA) calcualtion
5. EPIC version adjusted DunedinPACE, DNAmTL, epiTOC, and DNA methylation-based inflammation, smoking, and alcohol scores
6. Paired t tests and calculate effect size
